## 👩‍💻 About This Repository

This repository contains my personal solutions to the **#8WeekSQLChallenge** — a series of real-world inspired SQL case studies created by **Danny Ma**.

Each case study pushed me to think beyond basic queries and apply advanced SQL techniques including:

⭐ **CTEs (Common Table Expressions)**
⭐ **Window Functions & Ranking**
⭐ **DateTime Functions**
⭐ **Complex JOINs & Aggregations**
⭐ **CASE Statements**
⭐ **NULL Handling**
⭐ **Subqueries & Nested Logic**

> 💡 *My approach: For every question, I first build the logic in plain English, then translate it into SQL — making solutions easy to understand and replicate.*

## 🧠 My SQL Approach

```
📌 Step 1 → Understand the business question
📌 Step 2 → Identify which tables are needed
📌 Step 3 → Build the logic in plain English
📌 Step 4 → Write the SQL query
📌 Step 5 → Validate output & add insights
```

---

## 🏆 Key Learnings

- Writing **clean, readable SQL** using CTEs instead of nested subqueries
- Handling **real-world messy data** with NULL handling and data cleaning
- Thinking like a **Data Analyst** — not just writing queries, but deriving business insights
- Building **reusable query patterns** for common problems
